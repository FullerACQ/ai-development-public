# Coding-agent guidance

- Prioritize correctness, simplicity, and developer experience.
- Inspect the relevant code and follow the project's structure and conventions.
- Use the smallest complete change that solves the requested task.
- Preserve unrelated user work and existing error handling.
- Parse untrusted inputs at system boundaries and make failures visible.
- Run focused checks appropriate to the change before reporting completion.
- Prefer dedicated file tools and keep command output focused.
- Never commit credentials, personal data, or private organization material.
- Only commit, push, or open pull requests when the user requests it.
- State the result clearly, including any remaining blockers or unverified work.
